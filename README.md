# ML4SCI GENIE: GSoC 2026 Evaluation Tasks
**Applicant:** Kartavya Rustagi  
**Project:** Deep Graph Anomaly Detection with Contrastive Learning

This repository contains the evaluation task solutions for the Machine Learning for Science (ML4SCI) GENIE project for Google Summer of Code 2026.

### Repository Contents:
* `Common_Task_1.ipynb`: Convolutional Autoencoder for calorimeter image reconstruction, utilizing Global Max Scaling to handle extreme sparsity.
* `Common_Task_2.ipynb`: Baseline Graph Convolutional Network (GCN) for Quark/Gluon classification, featuring a custom SciPy KDTree implementation for portable Image-to-Graph conversion.
* `Specific_Task_1.ipynb`: Supervised Contrastive Learning implementation, including representation collapse diagnosis and linear probe evaluation.

*All notebooks include execution logs and outputs demonstrating successful training and evaluation.*
